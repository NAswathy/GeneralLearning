Lean Business Case/ Problem Statement 
Epic StatementFor  customers in targeted regional markets
 the integration is a way  to provide a direct ordering experience That also consolidates local ERPS. To provide seamless and comprehensive ordering solution in the region
Business Outcome HypothesisThe objective of this phase is to enable seamless partner access, product visibility, and basic transaction and opportunity management
A dedicated landing page for dealers will be implemented using existing HYPERLINK "http://TF.com"http://TF.com templates. This page will display recent campaigns, updates, news, and partner-specific announcements, providing a centralized entry point for dealer-related content.
A downloadable product list (SKU list) will be provided within the Dealer Portal. This list will include key commercial and regulatory information such as pricing, inventory availability, contract sizes, and compliance fields (e.g., Cartagena, PRTP, Fire Act). This enables partners to maintain accurate product catalogs and ensure regulatory adherence.
The portal will support web order creation and visibility for products belonging to non-E1 divisions (SAP D50 / SAP PR1). Core capabilities include price and stock harmonization across systems and access to web order history. This ensures partners have a consistent and reliable ordering experience for Korea-specific product portfolios.
The CRM module will enable dealers to capture, track, and update sales opportunities. Users will be able to link opportunities to leads, record progress updates, and monitor quotation activities—including pricing negotiations. This allows Thermo Fisher and its partners to maintain visibility into the sales pipeline and improve collaboration on revenue-generating activities.

MVP Requirements
Must have this:
Accounts: Invite a Colleague by the Partner to be enabled. Dealer flag should be available for the invitee. 
Accounts dashboard:  configurations to be enabled for the partners, Quote related submissions to be extended to KDP, Quote ID shall be passed to Checkout
Identity: ENV specific login/registration for the new domain, Invite a Colleague functionality to be extended for Korea dealers
Loyalty- Pass the dealer flag to the invited customer, Inviting existing customer with a new account link. Dealer data upload via bulk registration
Platform Gateway- Disable/enable existing country wise cookies for KR specific, Enable new erpTypes (SAP PR1 3000, SAP_D50_KR20) linked to Korean accounts. Get the erpTypes to CSR portal. For the KR ISO CODE, the erpType to be picked up as SAP PR1 3000 and SAP_D50_KR20, get the sku entitlement list for KR
Hybris- Product data and attributes to be loaded in Hybris and configured/entitled for the 2 new erpTypes, translations of the content on applicable places, Brands association for SKUs belonging to the new erps
Platform API- Create a new entitlement sku list for the new erpTypes, Pass the Hybris data core attributes for the Search and PDP, get list price from EDP, add the new erptype to the Pricing, availability related kafka topic for regular updates on the new erpType
PDP, Magellan - Display the entitled SKU PDP contents for login/guest user as per the new erpType setting for Korea dealers, display the different Pricing details configured for the new erpType, display WebOrderable, PVNO, WONV statuses for the skus based on erpTypes, get availability details for the entitle products for KR using PANDA API Integration for API for PR1
Search- Update the Solr query and Search algorithms based on the new erpTypes. Consume the Core, Rich attributes, Videos, images from the Platform APIs and Hybris data for the new erpType. Update the pricing details, availability details on SRP based on the respective APIs from Platform API team, Partner based entitlement changes (Country + UserID) (existing feature) for KR, Display Stock message Stock availability count for E1
Mandalorians- get the promotions that are eligible for the new erpType products, if available. Contact us info specific for the Korean region for the entitled SKUs
Cart- Get the pricing, availability details as per the new erpTypes, get the overall price calculated as per the new erpTypes, display SKU notes, display sku availability based on the location, look into oversees inventory
Checkout- Update SKU availability according to the new erpType, calculate the overall price as per the new erpType/location, For quotes, get the QuoteId and customer details from Accounts Dashboard and Post Purchase
Post purchase- Enable the new SKUs for the order history tracking, Update the order status across the SAP db and ERP, store the quoteIds and details of orders etc in the Accounts Dashboards for the users
